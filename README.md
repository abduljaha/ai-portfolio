# 🚀 AI & ML Engineer Portfolio

A premium, interactive 3D portfolio showcasing Generative AI projects, Large Language Model (LLM) architectures, and data-driven software engineering. Designed with a dark futuristic "Cyberpunk / AI" aesthetic, featuring interactive WebGL elements and seamless animations.

![Portfolio Preview](public/ai_abstract_visualization.jpg)

## 🌟 Live Demo
[**View Live Portfolio here**](https://abduljaha-portfolio.vercel.app/) *(Replace this link after deploying to Vercel)*

---

## ✨ Key Features

- **🤖 Interactive AI Twin Chatbot:** A custom floating chat interface ready to answer questions about skills, experience, and projects.
- **🏙️ 3D GitHub Contribution City:** A custom `Three.js` / `react-three-fiber` visualization that renders coding activity as an interactive 3D city.
- **📊 Live System Metrics Dashboard:** Simulated real-time production metrics (RAG Latency, Token Throughput, Vector DB Nodes) demonstrating backend architecture knowledge.
- **🌌 3D Space Background:** Animated particle system running smoothly in the background.
- **✉️ Working Contact Form:** Fully functional contact system powered by `EmailJS` with floating labels and form validation.
- **📱 Fully Responsive:** Beautifully adapts to mobile, tablet, and desktop screens with a Glassmorphism UI.

## 🛠️ Technology Stack

- **Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)

- **Icons:** [Lucide React](https://lucide.dev/) + Custom SVGs
- **Email Service:** [EmailJS](https://www.emailjs.com/)

## 💻 Local Development

### 1. Clone the repository
```bash
git clone https://github.com/abduljaha/ai-portfolio.git
cd ai-portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory and add your EmailJS API keys for the contact form:

```env
VITE_EMAILJS_SERVICE_ID=your_service_id
VITE_EMAILJS_TEMPLATE_ID=your_template_id
VITE_EMAILJS_PUBLIC_KEY=your_public_key
```

### 4. Start the Dev Server
```bash
npm run dev
```

Your app will be available at `http://localhost:5173`.
